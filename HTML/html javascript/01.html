A tag html script

A tag HTML script é usada para definir um script do lado do cliente (JavaScript).

O script elemento contém instruções de script ou aponta para um arquivo de script externo através do srcatributo.

Os usos mais comuns do JavaScript incluem manipulação de imagens, validação de formulários e alterações dinâmicas de conteúdo.

Para selecionar um elemento HTML, o JavaScript geralmente usa o document.getElementById()método.
